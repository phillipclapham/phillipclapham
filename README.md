### What I Build

- **[Levain](https://github.com/levainhq/levain)** — Portable cognitive-partnership memory + methodology kit. Ship the seed that grows a practice, not the grown practice — which transfers as a fossil. Memory that persists across sessions and stays *yours*: it lives on your machine, in a store you own and can read, inspect, and edit from outside any session. Nothing reaches long-term memory except through a path you govern; every governed change is recorded; a failed read shows up as *unknown* instead of a false all-clear. Built on anneal-memory as a layer-1 dependency. On [PyPI](https://pypi.org/project/levain/). Apache 2.0.
- **[anneal-memory](https://github.com/phillipclapham/anneal-memory)** — Open-source agent memory architecture. Four cognitive layers (episodic store, continuity file, Hebbian association, affective state) + an immune system spanning all four (citation-validated graduation, anti-inbreeding defense, principle demotion) + a hash-chained JSONL audit trail. Govern-not-trust, in code. The constructive existence proof for the harness paper's §9. On [PyPI](https://pypi.org/project/anneal-memory/), 12 framework integrations, 1,600+ tests, zero dependencies. MIT.
- **[Flow System](https://github.com/phillipclapham/flow-methodology)** — Distributed cognitive infrastructure for human-AI partnership. Multi-AI orchestration, real-time sensor pipelines, relay protocols, four-tier cost-optimized processing. The working harness instance behind the papers. Python, FastAPI, SwiftUI.
- **[FlowScript](https://flowscript.org)** — Semantic notation for high-density AI communication and encoded cognition. Compresses complex relationships into symbolic form that reveals structure verbose prose obscures. Hash-chained audit trails, typed semantic queries (`why()`, `tensions()`, `blocked()`), convergence certificates via stratified fixpoint computation (`@fix`). TypeScript + Python SDKs. The [live playground](https://flowscript.org) runs the notation in your browser. *Maintenance mode — the core concepts evolved into anneal-memory; the notation stays in daily use.* MIT.
- **[MicroChaos CLI](https://github.com/phillipclapham/microchaos-cli)** — WP-CLI load testing for staging environments where external load testing is restricted. PHP.
